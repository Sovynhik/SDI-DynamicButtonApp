## Описание

Приложение Windows Forms, демонстрирующее **динамическое создание элементов** и работу с **меню/панелью инструментов**.  

**Функционал (по варианту 16):**

1. **Кнопка «Создать кнопку»**  
   - При клике создаётся новая кнопка в случайных координатах.  
   - Начальная надпись – `0`.  
   - Случайный цвет фона.  

2. **Таймер (1 сек.)**  
   - Каждую секунду увеличивает число на **каждой** кнопке на `+1`.  

3. **Контекстное меню** (правый клик на кнопку)  
   - Пункт **«Удалить»** – удаляет кнопку.  

4. **Кнопка «Удалить все»**  
   - Запрашивает подтверждение через `MessageBox`.  
   - Удаляет все динамические кнопки.  

5. **Меню**  
   - `Файл → Выход` (с мнемоникой).  

6. **Панель инструментов**  
   - Кнопка **«Создать кнопку»** (дублирует основную).
